{%- comment -%} SNAPStart awardee cards, driven by `_data/snapstart.yml`. Pass `round` to show only that round's awardees, e.g. `{% include snapstart_awardees.html round=1 %}`. Without it, every round is listed. Logos are picked up by file name: an entry with `round: 1` and `id: coas` shows `images/snapstart/round_1_logos/coas.` as soon as that file exists. Until then the card shows a placeholder tile with the entry's `short` label (or its initials). {%- endcomment -%} {%- assign awardees = site.data.snapstart -%} {%- assign round_filter = include.round | append: "" -%} {%- assign logos = site.static_files | where_exp: "f", "f.path contains '/images/snapstart/'" -%}
