{%- comment -%} "Upcoming SNAP Events" list, driven by `_data/events.yml`. Each entry may set: name, date (YYYY-MM-DD), website, category, flyer, description. Only `name` and `date` are required. `category` may be a single string or a list of strings; each renders as its own bubble. `description` is rendered as Markdown — links, emphasis, lists, and multiple paragraphs all work. It must be written in events.yml as a literal block (`|-`), not a folded one (`>-`): folding replaces every newline with a space, which leaves Markdown with no paragraph or list breaks to act on. An event disappears once its date has passed. That is filtered twice on purpose: in Liquid at build time, and again in the browser on page load, so a page built weeks ago (Jekyll only re-runs on a push) never shows a stale event. The cutoff is the end of the event day — midnight UTC the day after — so an event stays listed while it is happening. Pass `category` to only show events with a category that starts with that string, e.g. `{% include upcoming_events.html category="Stance on Science" %}` picks up both "Stance on Science" and "Stance on Science GA". Pass `compact=true` to render a condensed list — just date, name, and category bubble per row — with a toggle to expand a row and show its flyer and remaining details (description, link). Pass `empty_message` to override the text shown when no events are listed. {%- endcomment -%} {%- assign now_seconds = 'now' | date: '%s' | plus: 0 -%} {%- assign events = site.data.events | sort: 'date' -%} {%- assign filter_category = include.category -%} {%- assign filter_len = filter_category | size -%} {%- assign compact = include.compact -%}
